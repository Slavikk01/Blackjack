# Ігри

Проєкт містить Blackjack та гру «Камінь, ножиці, папір», написані на Python.

## Запуск

1. Відкрийте термінал у папці проєкту.
2. Виконайте команду:

```bash
python main.py
```

## Тести

Запустіть усі unit-тести командою:

```bash
python -m unittest discover -v
```

## Функції

- роздача карт
- підрахунок очок
- перевірка blackjack
- хід гравця та дилера
- логіка переможця
- система ставок
- вибір гри перед запуском

## Інтерфейс гри

`GameInterface` у `game_interface.py` — це структурний контракт на основі
`Protocol`: він описує властивість `players` та метод `make_move(player)`.
Інша гра може відповідати контракту без успадкування від нього — достатньо
реалізувати ці члени. `BlackjackGame` і `RockPaperScissorsGame` є прикладами
реалізації контракту.

## Автор

Проєкт створено на основі прикладу гри Blackjack.

## Профілі Blackjack та текстові файли

Перед першим запуском відкрийте `profiles.txt` у будь-якому текстовому редакторі та додайте профілі. Один профіль — один рядок у форматі:

```text
Ім'я|Кількість_фішок
Андрій|1000
Олена|2500
```

Збережіть файл і запустіть `python main.py`. У меню Blackjack виберіть номер потрібного профілю. Якщо файл не містить жодного профілю, гра не почнеться — спочатку потрібно додати профіль у `profiles.txt`. Створення або зміна імені та початкової кількості фішок відбувається у файлі, не в терміналі.

Після кожного зіграного раунду актуальна кількість фішок автоматично записується назад у `profiles.txt`. Тому для нового профілю просто додайте новий рядок, а щоб змінити баланс вручну — відредагуйте відповідний рядок, коли гра не запущена.

`results.txt` містить історію раундів: дату й час, ім'я гравця, номер раунду, результат і баланс після раунду. Нові результати додаються в кінець файлу. Файл `logs/game.log` залишається технічним журналом програми.
