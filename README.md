# Blackjack Game

Це простий проект гри в blackjack, написаний на Python.

## Запуск

1. Відкрийте термінал у папці проєкту.
2. Виконайте команду:

```bash
python main.py
```

## Функції

- роздача карт
- підрахунок очок
- перевірка blackjack
- хід гравця та дилера
- логіка переможця
- система ставок

## Автор

Проєкт створено на основі прикладу гри Blackjack.
