# Ігри

Проєкт містить Blackjack та гру «Камінь, ножиці, папір», написані на Python.

## Запуск

1. Відкрийте термінал у папці проєкту.
2. Виконайте команду:

```bash
python main.py
```

## Тести

Запустіть усі unit-тести командою:

```bash
python -m unittest discover -v
```

## Функції

- роздача карт
- підрахунок очок
- перевірка blackjack
- хід гравця та дилера
- логіка переможця
- система ставок
- вибір гри перед запуском

## Інтерфейс гри

`GameInterface` у `game_interface.py` — це структурний контракт на основі
`Protocol`: він описує властивість `players` та метод `make_move(player)`.
Інша гра може відповідати контракту без успадкування від нього — достатньо
реалізувати ці члени. `BlackjackGame` і `RockPaperScissorsGame` є прикладами
реалізації контракту.

## Автор

Проєкт створено на основі прикладу гри Blackjack.


## Введення та виведення через файли

За замовчуванням програма працює з файлами:
- `input.txt` — відповіді користувача (кожна відповідь з нового рядка);
- `output.txt` — повний текст роботи програми, включно з повідомленнями з модулів гри.

1. Створіть у папці проєкту файл `input.txt`.
2. Запишіть у нього відповіді в тому самому порядку, у якому програма запитує їх у консолі.
3. Для Blackjack послідовність зазвичай така: `1` (обрати Blackjack), ім'я, сума ставки, `1` (взяти карту) або `2` (зупинитися), потім `1` (зіграти ще раз) або `2` (завершити).
4. Запустіть `python main.py`.
5. Перегляньте результат у `output.txt`.

Приклад послідовності наведено у файлі `input_example.txt`. Це шаблон: за потреби змініть відповіді. Якщо у файлі не вистачить рядків, програма запише відповідне повідомлення в `output.txt`.

Щоб запустити гру у звичайному інтерактивному режимі, використайте `python main.py --console`.
Можна також задати інші файли: `python main.py --input my_input.txt --output my_output.txt`.
